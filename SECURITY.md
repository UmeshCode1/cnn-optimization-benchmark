# Security Policy

We actively maintain and provide security updates for the following versions of the **CNN Optimization Benchmark Platform**:

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| 1.x.x   | :x:                |

---

## Reporting a Vulnerability

The safety and integrity of the **CNN Optimization Benchmark Platform** is a top priority. If you discover a security vulnerability, we appreciate your help in disclosing it to us responsibly.

### How to Report

1. **Do not create a public issue** for potential security vulnerabilities.
2. Please report the vulnerability directly via **Private Vulnerability Reporting** on GitHub:
   - Navigate to the [Security Advisories](https://github.com/UmeshCode1/cnn-optimization-benchmark/security/advisories) tab.
   - Click **"Report a vulnerability"**.
   - Provide detailed steps to reproduce the issue, proof of concept, and impacted components.
3. Alternatively, contact the maintainer directly at: **[GitHub @UmeshCode1](https://github.com/UmeshCode1)**.

---

### Response Process

* **Acknowledgment**: We will acknowledge receipt of your vulnerability report within **48 hours**.
* **Assessment & Fix**: We will assess the severity and develop a patch in a private fork.
* **Disclosure**: Once a fix is verified and released, a security advisory will be published crediting the reporter.
